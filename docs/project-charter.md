# Project Charter: Enterprise AI Value Tracker

## 1. Business Problem

Organisations are increasingly adopting generative AI tools, but lower model prices or faster task completion do not automatically translate into business value.

A meaningful evaluation must consider usage costs, human effort, output quality, rework, and the financial impact of adopting AI-assisted workflows.

This project develops a transparent analytical framework to compare AI pricing trends with the economic performance of selected business tasks.

## 2. Primary Research Question

How have published prices for selected AI models changed over time, and under what conditions can AI-assisted workflows reduce the total cost of completing a business task while maintaining acceptable quality?

## 3. Research Objectives

1. Collect and validate published AI model pricing observations.
2. Compare historical prices using dated evidence and consistent units.
3. Calculate API usage costs under different workload assumptions.
4. Compare manual and AI-assisted task performance.
5. Evaluate cost per accepted output, potential savings, and break-even points.
6. Develop evidence-based recommendations for enterprise AI adoption.

## 4. Scope

### Included
- Selected models from OpenAI and Anthropic.
- Published input and output token prices.
- Historical price comparisons where reliable dated evidence exists.
- One controlled business-task comparison.
- Human review time, task duration, quality and rework.
- Financial modelling, sensitivity analysis and visualisation.

### Excluded
- Exhaustive analysis of every AI provider or model.
- Claims about the entire AI industry based on a small sample.
- Paid API consumption where a free alternative is available.
- Unsupported estimates presented as measured results.
- Claims of enterprise-wide savings without appropriate evidence.

## 5. Proposed Hypotheses

**H1:** Published token prices for selected models have changed over the observation period.

**H2:** Lower token prices do not necessarily produce proportionally lower total task costs.

**H3:** The economic advantage of AI-assisted work depends on human review effort, output quality, task complexity and usage volume.

**H4:** The financial case for AI adoption varies according to workload and labour-cost assumptions.

These hypotheses will be evaluated using the available evidence. They are not assumed to be true in advance.

## 6. Key Metrics

- Input cost per million tokens.
- Output cost per million tokens.
- Estimated API cost per task.
- Manual task completion time.
- AI-assisted task completion time, including review.
- Cost per accepted output.
- Percentage time saved.
- Percentage cost difference.
- Quality score and rework rate.
- Break-even task volume and estimated ROI.

## 7. Methodology

1. Identify authoritative pricing sources.
2. Record model identifiers, prices, units, effective dates and source URLs.
3. Standardise prices into comparable units.
4. Calculate costs for defined token-consumption scenarios.
5. Select a repeatable business task and define a consistent quality rubric.
6. Compare manual and AI-assisted performance.
7. Calculate financial outcomes under explicit assumptions.
8. Document findings, limitations and recommendations.

## 8. Tools

- GitHub for version control and project documentation.
- Excel or Google Sheets for data management and financial calculations.
- Public provider documentation for pricing evidence.
- Optional Python notebooks for reproducible analysis.

## 9. Success Criteria

The initial project will be considered complete when it contains:

- A documented research methodology.
- A source-backed pricing dataset.
- A working and validated cost calculator.
- A documented task comparison.
- A dashboard with clearly defined metrics.
- An executive summary with evidence-based recommendations.
- A reproducible record of assumptions, formulas and limitations.

## 10. Project Constraints

The initial delivery is limited to two days and prioritises a focused, credible minimum viable project.

The project will use free tools and public evidence wherever possible. Missing historical data will be documented rather than fabricated. Any illustrative financial scenarios will be explicitly labelled.

## 11. Intended Audience

Recruiters, hiring managers and interviewers assessing business analysis, technology consulting, quantitative reasoning, AI evaluation and commercial decision-making skills.

## 12. Expected Outcome

A public, reproducible portfolio project demonstrating how to evaluate AI economics and translate quantitative analysis into practical business recommendations.
